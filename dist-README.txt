Nielsen Processor v4.0
======================
No installation required.

── WINDOWS USERS ──────────────────────────────────────
1. Unzip the folder anywhere (Desktop, D:\ drive, etc.)
2. Double-click: START-Windows.bat
3. A black window opens — keep it open
4. Your browser opens automatically at http://localhost:3000
5. Use the app. Close the black window when done.

── MAC USERS ───────────────────────────────────────────
1. Unzip the folder anywhere
2. Double-click: START-Mac.command
   (If blocked: Right-click → Open → Open anyway)
3. A terminal opens — keep it open
4. Your browser opens at http://localhost:3000
5. Use the app. Close the terminal when done.

── IMPORTANT ───────────────────────────────────────────
• Keep ALL files together — do NOT move index.html
  or the DQChecks folder away from the exe
• The app only works while the black/terminal window is open
• Use Chrome or Edge for best experience
• Your saved Azure connections are stored in
  azure-config.json (encrypted with your password)

── TROUBLESHOOTING ─────────────────────────────────────
• "Windows protected your PC" → Click "More info" → "Run anyway"
• Mac "cannot be opened" → System Preferences → Security → Allow
• Port already in use → Close other Nielsen windows first
• Browser shows "can't connect" → Wait 5 seconds, refresh
